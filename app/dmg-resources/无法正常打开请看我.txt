        小红书自运营系统 · macOS 首次启动指引
════════════════════════════════════════════════════════════════════

▎ 为什么需要这一步 ?

  本应用使用「Ad-hoc 签名」打包,没有花钱购买 Apple 开发者证书
  ($99/年)。macOS 安全策略 (Gatekeeper) 会拦截这类应用,提示
  「已损坏」或「无法验证」。

  这并不是真的损坏。只需 1 行命令把应用从「隔离区」里释放出来,
  之后双击应用就能正常用,**不用再做这一步**。

  (后续每次自动更新或客服推新版,也不用重做)

──────────────────────────────────────────────────────────────────

▎ 安装步骤 (3 步, 全程 < 1 分钟)

  ▍ 第 ① 步:把应用拖到 Applications 文件夹
  ────────────────────────────────────
  本窗口左边是「小红书自运营」图标, 中间是「Applications」快捷方式。
  鼠标按住左边图标, 拖到中间的 Applications 图标上松开。完成。


  ▍ 第 ② 步:打开「终端」(Terminal)
  ────────────────────────────────────
  按 ⌘ (Command) + 空格 → 调出 Spotlight 搜索 → 输入「终端」→ 回车。
  会弹出一个黑色或白色的纯文字窗口, 大概长这样:

   ┌─────────────────────────────────────────────────────┐
   │  ●  ●  ●        username — -zsh — 80×24            │
   ├─────────────────────────────────────────────────────┤
   │                                                     │
   │  Last login: Mon May 18 00:00 on ttys000            │
   │  username@MacBook ~ %  ▮                            │
   │                                                     │
   │                                                     │
   └─────────────────────────────────────────────────────┘

  光标 ▮ 在等你输入。下一步把命令贴进来。


  ▍ 第 ③ 步:复制下面这一行, 粘贴到终端, 回车
  ────────────────────────────────────
  全选下面这一整行 (从 xattr 到 .app 末尾), ⌘ + C 复制:

     xattr -cr /Applications/小红书自运营.app

  切到终端, ⌘ + V 粘贴, 按回车 ↩。

  执行完没有任何输出,看起来好像没反应 —— 这就是成功了。
  (终端有个习惯:操作成功时不打印任何东西)


──────────────────────────────────────────────────────────────────

▎ 启动应用

  打开「访达」→「应用程序」→ 双击「小红书自运营」, 应该直接启动。

  如果还是弹「已损坏」:

  方法 A) 打开「系统设置」→「隐私与安全性」, 拉到底部, 应该有
          一行「已阻止"小红书自运营"」+ 一个「仍要打开」按钮。
          点「仍要打开」, 输入电脑密码确认。

  方法 B) 回到第 ③ 步, 检查命令是否完整粘贴 (要 xattr 开头,
          路径 /Applications/小红书自运营.app 结尾)。
          再跑一次。

──────────────────────────────────────────────────────────────────

▎ 如果第 ③ 步报错「Operation not permitted」

  你的 /Applications 可能需要管理员权限。改用下面带 sudo 的版本:

     sudo xattr -cr /Applications/小红书自运营.app

  回车后会让你输电脑登录密码。输入时屏幕不显示任何字符 (这是
  正常的安全设计, 不是卡住), 输完直接回车即可。

──────────────────────────────────────────────────────────────────

▎ 命令含义解释 (好奇可看)

  ▍xattr  = 操作文件「扩展属性」的命令
  ▍-c     = clear, 清除所有
  ▍-r     = recursive, 递归处理整个 .app 内所有文件
  ▍要清的属性: com.apple.quarantine ── macOS 标记「已下载」用,
              Gatekeeper 看到这个标记就拦截。清掉就放行。

  整条命令 = 把「小红书自运营.app」从「最近下载」名单里删掉,
            让 macOS 当它是一个本地正常应用。

──────────────────────────────────────────────────────────────────
