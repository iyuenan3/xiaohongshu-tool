# PRD — 小红书自运营系统
<!-- 产品意图（产品类项目）。 -->

## 目标
让小红书运营者用 AI 自动化日常运营，**零 LLM 配置门槛** (代付) + **零运营操作门槛** (AI 代点赞 / 评论 / 发布 / 数据 / 定时工作流)。商业模式：软件 ¥399 一次性买断 + LLM 服务月费 (具体定价运营时定，不写文档)。

## 用户问题
- 手动刷小红书做运营 (点赞 / 评论 / 发笔记 / 看数据) 重复累人。
- 想用 AI 但 BYOK 门槛高：要自己找 LLM 供应商 + 申请 key + 充值 + 配置。
- 现成 AI 工具不懂小红书操作、不能直接操作账号。

## 成功指标
⚑ pre-launch 未定量。首版按"首月销量验证"决定是否升级法律主体 (个人 → 个体户)；公测前定 D3 (产品名) + D5 (客服渠道)。

## UX 哲学
- **零配置激活**：输激活码 → 立即可聊可操作 (LLM 配置中转下发)。
- **所有交互走 AI 聊天**：不做工具按钮面板 (UX 复杂、用户明确否决)；用户说自然语言，AI 选工具。
- **敏感操作弹确认**：发布 / 评论 / 点赞 / 收藏默认二次确认 (可设置自动模式)。
- **配额可视 + 软阻断**：Settings 显示本月剩余 ¥；耗尽 → disable chat + banner「下月 1 日重置 + 联系客服」。
- **dev 暗号逃生口**：反馈框输暗号解锁 BYOK 配置 (中转宕机 / 要中转不支持的模型 / 内部 debug)。
- **风控软提示**：频率护栏提示不硬拦，尊重用户判断。

## 商业模式
软件买断 + LLM 月续费；默认自动续费 (服务端月度重置)；未付费 → 手动 suspend (15 天软停：软件能开但 chat 锁 + 续费 banner) → 仍不续 → revoke 硬停。
