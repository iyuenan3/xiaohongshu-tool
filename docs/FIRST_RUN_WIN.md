# 首次启动指南（Windows）

> 由于本软件采用无证书发布（不向 Microsoft / Verisign 等支付数百美元/年的代码签名证书费用），首次启动时 Windows SmartScreen 会提示"未识别的应用"。按下方步骤一次性放行即可。

---

## 方法 A · SmartScreen 放行（推荐）

**适用版本：** Windows 10 / 11

1. 双击下载的 `小红书自运营 Setup 0.1.0.exe`
2. SmartScreen 弹出"**Windows 已保护你的电脑**"蓝色窗口
3. 点击窗口里的"**更多信息**"链接（小字，容易错过）
4. 出现"**仍要运行**"按钮，点击它
5. 后续按安装向导操作（默认安装到 `C:\Users\<your-name>\AppData\Local\Programs\小红书自运营\`）
6. 安装完成 → 桌面会出现快捷方式

> ⚠️ **重点**：第 3 步的"更多信息"是个超链接，不是按钮，颜色较浅。如果直接点"不运行"，需要重新双击 .exe。

---

## 方法 B · 关闭 SmartScreen（不推荐）

如果你的电脑频繁安装未签名软件想免去每次确认：

1. **设置 → 隐私和安全性 → Windows 安全中心 → 应用和浏览器控制 → 基于声誉的保护**
2. 把"**检查应用和文件**"开关关闭

**警告**：这会降低系统对未知软件的保护，仅在你清楚自己在做什么时操作。

---

## 方法 C · 解除文件锁定（高级用户）

如果方法 A 仍弹不出"更多信息"：

1. 在 .exe 上点击右键 → **属性**
2. 在"常规"页底部勾选"**解除锁定（U）**"复选框
3. 点确定 → 重新双击运行

---

## 防病毒软件误报

少数防病毒软件（如卡巴斯基、火绒）可能把 .exe 误报为可疑（因为未签名）。处理：

- **火绒**：弹窗时选"信任此程序"
- **卡巴斯基**：设置 → 威胁与排除 → 排除项 → 添加 `小红书自运营.exe`
- **Windows Defender**：参照方法 A 即可，已知不误报

## 常见问题

### Q: 安装过程中卡在某个步骤

A: NSIS 安装器解压含 100+ 文件，可能需要 5-15 秒。等待即可。

### Q: 安装完成后双击桌面图标没反应

A: 启动需要 5-15 秒（解压 Chromium + 启动 Go MCP）。打开"任务管理器"看是否有"小红书自运营.exe"和"xiaohongshu-mcp.exe"进程。

### Q: 升级到新版本还需要再次 SmartScreen 放行吗？

A: **不需要**。app 内自动更新在安装时已经被 SmartScreen 信任，新版替换不会触发拦截。**但如果你手动下载新版 .exe 重新装**，仍然会弹 SmartScreen（按方法 A）。

### Q: 我用的是 Windows 7/8

A: 不支持。最低要求 Windows 10 64-bit。

### Q: ARM 版 Windows（如 Surface Pro X / Snapdragon X Elite）

A: 暂不提供 ARM 原生版本。可以走 Windows 10/11 的 x64 模拟模式运行，但性能会下降约 20%。

## 后续使用

第一次成功打开后会看到激活页：

1. 输入客服发给你的激活码（格式 `XHS-XXXX-XXXX-XXXX-XXXX`）
2. 点"激活"
3. 1-2 秒后跳转主界面，自动打开小红书登录窗口
4. 在小红书窗口扫码登录账号
5. 回到主界面，右侧 AI 助手可用

## 卸载

**控制面板 → 程序和功能 → 找到"小红书自运营" → 卸载**

或：**设置 → 应用 → 应用和功能 → 小红书自运营 → 卸载**

彻底清理用户数据：

```
del /q "%APPDATA%\xhs-app\*.*"
```

> 注意：这会删除激活信息、对话历史、cookies。换电脑前**不要**清，先联系客服换绑。
