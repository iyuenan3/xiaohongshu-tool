# 首次启动指南（macOS）

> 由于本软件采用无证书发布（不向 Apple 支付每年 $99 的开发者证书费用），首次启动时 macOS 会提示"无法打开"。这是 macOS Gatekeeper 的标准提示，**不代表软件有问题**，按下方步骤放行即可，仅需操作一次。

---

## 方法 A · 右键打开（推荐，最快）

**适用版本：** macOS 10.15 ~ 14.x

1. **下载 dmg**，双击挂载。
2. 把"小红书自运营.app"拖到"应用程序"文件夹。
3. 打开"应用程序"文件夹，找到"小红书自运营"。
4. **按住 Control（^）键，单击图标**，选择"**打开**"。
5. 弹出的对话框中点击"**打开**"按钮（这次会出现，而不是只有"取消"）。
6. 之后双击就能直接打开了。

> ⚠️ **重点**：必须用"右键 → 打开"而不是双击。双击 macOS 会直接拒绝。

---

## 方法 B · 系统设置放行

**适用版本：** macOS 13.x ~ 最新

1. 下载 dmg，双击挂载，把 app 拖到"应用程序"。
2. 双击 app — 会弹出"无法打开"的提示，**点取消**（不要删）。
3. 打开 **系统设置 → 隐私与安全性**。
4. 滚动到底部，会看到一条："**已阻止打开"小红书自运营"，因为它来自身份不明的开发者**"。
5. 点旁边的"**仍要打开**"按钮。
6. 再次双击 app，弹框点"打开"即可。

---

## 方法 C · 终端解除隔离属性（高级用户）

如果上面两种都不行（极少数情况），打开 **终端（Terminal）**，运行：

```bash
sudo xattr -dr com.apple.quarantine "/Applications/小红书自运营.app"
```

输入开机密码后，再双击 app 即可。

## 常见问题

### Q: 这个软件安全吗？为什么 macOS 拦截？

A: **安全**。macOS 拦截任何**未购买 Apple 开发者证书签名**的软件，跟软件本身质量无关。我们选择无证书发布是为了把价格压到 ¥399（带证书发布需要每年支付 Apple $99 + 公证流程，最终转嫁到售价上）。源代码经过严格审计，详见 [产品安全声明](#)。

### Q: "无法验证开发者" / "macOS 无法验证此 app 是否包含恶意软件"

A: 一样按方法 A 或 B 操作。本质都是 Gatekeeper 提示。

### Q: 升级到新版本还需要重做吗？

A: **不需要**。一旦 app 被放行，后续从 app 内自动更新或重新下载新 dmg 替换，都不会再触发 Gatekeeper 拦截（macOS 会记住"用户已信任此 app"的状态）。

### Q: 我把 app 移动到了其他位置（如桌面），又被拦截了

A: macOS 会重新隔离移动后的 app。把它移回"应用程序"文件夹，或者再用一次方法 A。

### Q: 我点了"打开"但什么都没发生

A: 首次启动需要 5-15 秒（要解压缩 + 启动 Electron + 启动内嵌 Go 服务）。如果一直没反应，打开"活动监视器"看是否有"小红书自运营"进程。

## 卸载

把"应用程序 → 小红书自运营.app"拖到废纸篓即可。如果想彻底清理用户数据：

```bash
rm -rf ~/Library/Application\ Support/xhs-app/
```

> 注意：这会删除你的激活信息、对话历史、小红书 cookies。如果换电脑使用，**不要删除**，先联系客服换绑。
